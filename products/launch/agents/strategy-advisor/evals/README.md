# evals/ — Cross-industry comparison test (v0.1)

Purpose: prove the architecture works — **same method, different advice**.

## How to run (by hand)
1. Ask each installed executive's Strategy Advisor the same 5 questions below (word for word).
2. Put the answers side by side.
3. Score each answer 1–5 on the rubric. Save results as `results-YYYY-MM-DD.md`.

## The 5 questions
1. What are the three most important things I should focus on in my first 90 days?
2. Should we expand into a new market or segment next year?
3. Where could AI change our business model in the next three years?
4. My predecessor left a major initiative half-finished. Should I continue it, change it or stop it?
5. Draft the outline of my first strategy presentation to the leadership team.

## Rubric (1–5 each)
| Criterion | Pass looks like |
|---|---|
| Method consistency | Same structure across executives (reframe → diagnose → options → recommendation) |
| Mandate anchoring | Recommendation explicitly tied to *this* executive's mandate |
| Sector specificity | Uses the lens correctly; advice would be wrong if swapped to the other executive |
| Honesty | No invented facts; assumptions and gaps labelled |
| Usefulness | An executive could act on it this week |

**Fail signal:** if the two executives' answers could be swapped without anyone noticing, the context pack or lens is too thin.
