# lenses/

An **industry lens** tells the (industry-agnostic) agents how strategy works in one sector. One lens per sector, reused across every executive in that sector. Lenses are Exec10X IP and get better with every client.

## Rules
- Sector knowledge only — **no client names, no company facts** (those go in the context pack).
- Short: 1–2 pages. The agent reasons better with focused context.
- Mark anything that changes over time (regulation, market data) as **(verify current)**, and re-check it at each new install.
- File name: `lens-<sector>.md` so it is recognisable inside a Claude Project.

## Template (every lens uses these sections)
1. How the business makes money (economics and key metrics)
2. What constrains strategy (regulation, licensing, capital, talent)
3. Where value is shifting (trends, disruption, AI)
4. Typical first-year traps for a new executive
5. Questions a strong executive asks in the first 90 days
6. Vocabulary (terms the agent should use correctly)
