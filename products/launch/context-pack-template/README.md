# context-pack-template/

Copy this folder into `SusanDana Co/clients/<exec>/context-pack/` for each new executive. Never fill it in here.

| File | Filled from | When |
|---|---|---|
| `mandate.md` | Search/Select brief + kickoff interview | Install |
| `success-blueprint.md` | `interview-intelligence` Success Blueprint agent output | Install |
| `company-profile.md` | Company Intelligence agent output | Install |
| `stakeholders.md` | Kickoff interview, then listening tour | Install, then monthly |
| `priorities.md` | Kickoff interview, then executive | Monthly refresh |
| `decisions-log.md` | Context-update blocks from the advisor | Monthly refresh |

Keep each file short and factual. If something is unknown, write "Unknown — to find out", never a guess.
